# Omoide 视频人物相册 · 中文改进版

在本机分析视频中的人脸，自动整理人物，并快速找到人物出现的时间段。

本项目基于 [EinAeffchen/Omoide](https://github.com/EinAeffchen/Omoide) v0.7.5，增加中文视频相册、人物时间轴、可撤销纠错及视频颜色还原等功能。它是独立维护的非官方改进版。

## 下载与打开

在本仓库 **Releases** 下载 `Omoide-Video-Album-…-win-x64.zip`，完整解压到可写的文件夹，双击 **Omoide.exe**。

1. 首次打开，选择存放资料库和缓存的位置。程序会新建 `Omoide-Data` 文件夹，无须预先创建 P 盘，也无须安装 Python。
2. 添加本机文件夹或已映射的 NAS 文件夹，扫描建立视频索引与封面。
3. 选择需要分析的视频，点击识别。首次识别需要联网下载 InsightFace 模型，下载后可本地运行。
4. 进入人物页，查看出现片段；点击时间段可跳转播放。

支持 Windows 10/11 x64。人脸模型通过 ONNX Runtime 运行，优先使用可用的 DirectML，失败时可回退 CPU。实际运行后端可在“模型与参数”页查看。软件页面默认位于 `http://127.0.0.1:8123`，本地配套服务使用 18124—18126 端口。

如果另一份相册已经运行，请先正常关闭，再打开本版本。便携包启动器会检查端口，避免把配套服务连接到另一份资料库。

## 主要功能

| 功能 | 行为 |
| --- | --- |
| 视频相册 | 预览播放、来源文件夹侧栏、文件夹计数、搜索、扫描更新及全选未识别视频 |
| 人物检索 | 按人脸次数、涉及视频数、最新视频等排序，支持无名人物直接勾选合并 |
| 出现时间轴 | 视频中各人物的检测区间、缩略图、点击回放；人物页可导出时间表 |
| 首次出现 | 独立入口，按人物最早出现的视频日期归档，最近日期在上 |
| 正脸与侧脸 | 正脸作为建组参考；可可靠匹配的侧脸归入同一人物，否则保留待确认 |
| 整段纠错 | 按视频和时间范围转移、拆出或排除人脸，支持撤销，保留后续新增结果 |
| 不同人物限制 | 标记两人不是同一个人，自动与手动合并遵守限制 |
| 局部精查 | 对指定范围加密采样，补充并去重，不清空已有识别结果 |
| 缓存与资源 | 人物页面缓存、CPU 档位、任务结束自动卸载人脸模型 |
| 视频还原 | 读取视频颜色类型，另存 SDR/HLG 成片，显示进度与成功标记 |
| 成片关联 | 成片在来源文件夹中呈现；只有核验成片入库后才隐藏原灰片，不删除原片 |
| 模型与参数 | 显示实际模型、执行后端、有效采样、归类阈值与存储位置，区分配置和生效状态 |

## 模型与采样

当前身份模型为 InsightFace `buffalo_l / w600k_r50.onnx`，检测器为 `det_10g.onnx`。这里的 `buffalo_s` 选项只替换检测器，保持身份特征模型不变。

常规均匀采样间隔为 `max(2秒, 视频时长÷1800)`；检测阶段不再缩减已经采样的画面。局部精查支持更密的采样，单次最多 10 分钟、2400 帧。时间段来自实际检测点，短暂出现、遮挡、严重模糊仍可能漏检，边界可点击回放核对。

“正脸度”是由关键点估计的姿态指标，不是身份置信度。模型、阈值和自动分组不能保证所有素材都正确；待确认、纠错和不同人物限制用于处理不可靠结果。公开测试成绩不等于本软件在某一资料库上的准确率。

## 数据与升级

- 视频留在用户选择的目录中；NAS 只负责存储，推理在运行程序的 Windows 电脑完成。
- 下载包包含程序、前端、运行库、还原组件和使用说明，不包含个人视频、人脸库、用户名密码、预训练人脸权重或开发者本机配置。
- 本项目没有收集视频或人脸的遥测功能；模型首次下载及配置的版本检查需要访问相应服务。
- 升级前备份自己的资料库；识别或还原任务进行时不要替换程序。不会自动导入、迁移或清空另一安装中的资料库。
- `storage.json` 由首次启动生成，记录数据位置。资料库可在软件设置中管理；移动存储位置前应正常关闭程序并完整备份。

## 源码与构建

源码目录：`app/` 后端，`frontend/` React 界面，`desktop/` Windows 启动器与配套服务，`restore-core/` 颜色还原核心。

前端使用已有依赖：

```powershell
cd frontend
npm ci
npm run build
```

后端依赖见 `pyproject.toml` 与 `uv.lock`，使用 Python 3.12。上游的 `main.spec` 用于完整桌面构建；便携包的配套启动器通过 `desktop/build_launcher.ps1` 构建。`UPSTREAM.json` 记录来源版本。二进制增量重建方法见 `docs/PUBLIC_BUILD.md`。
